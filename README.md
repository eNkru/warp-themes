# Warp Themes

A collection of **503 terminal color themes** for [Warp](https://warp.dev), converted from the [iTerm2 dynamic-colors](https://github.com/mbadolato/iTerm2-Color-Schemes) collection.

## Quick Start

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/warp-themes.git
cd warp-themes

# Install all themes
cp themes/*.yaml ~/.warp/themes/

# Restart Warp, then go to Settings → Appearance → Themes
```

## Installation

### Option 1: Copy all themes

```bash
cp themes/*.yaml ~/.warp/themes/
```

### Option 2: Copy specific themes

```bash
cp themes/Dracula.yaml ~/.warp/themes/
cp themes/Nord.yaml ~/.warp/themes/
cp themes/Catppuccin_Mocha.yaml ~/.warp/themes/
```

### Option 3: Symlink (keeps themes updated with repo)

```bash
ln -sf "$(pwd)/themes" ~/.warp/themes/warp-themes
```

After installing, restart Warp and navigate to **Settings → Appearance → Themes**.

## Re-converting Themes

If you want to convert the iTerm themes yourself (e.g., after an upstream update):

```bash
./convert.sh
```

This reads all `.sh` files from `iterm-dynamic-colors/` and generates corresponding `.yaml` files in `themes/`.

## Theme Format

Each Warp theme follows this structure:

```yaml
name: Theme Name
details: "darker"
accent: "#RRGGBB"
background: "#RRGGBB"
foreground: "#RRGGBB"

terminal_colors:
  bright:
    black: "#RRGGBB"
    red: "#RRGGBB"
    green: "#RRGGBB"
    yellow: "#RRGGBB"
    blue: "#RRGGBB"
    magenta: "#RRGGBB"
    cyan: "#RRGGBB"
    white: "#RRGGBB"
  normal:
    black: "#RRGGBB"
    red: "#RRGGBB"
    green: "#RRGGBB"
    yellow: "#RRGGBB"
    blue: "#RRGGBB"
    magenta: "#RRGGBB"
    cyan: "#RRGGBB"
    white: "#RRGGBB"
```

See [WARP_THEME_SPEC.md](WARP_THEME_SPEC.md) for the full specification.

## Color Mapping

The conversion maps iTerm2's ANSI escape sequences to Warp's YAML format:

| iTerm2 Slot | Description | Warp Field |
|-------------|-------------|------------|
| `P0` - `P7` | Normal colors (black → white) | `terminal_colors.normal` |
| `P8` - `Pf` | Bright colors (black → white) | `terminal_colors.bright` |
| `Pg` | Foreground | `foreground` |
| `Ph` | Background | `background` |
| `Pl` | Cursor | `accent` |

The `details` field is automatically set to `"darker"` or `"lighter"` based on background luminance.
